# To-Do List — Manual QA Testing Portfolio

## About the Project
This repository documents my practical learning of manual software testing using a To-Do List application as a training example.

The project focuses on test design, bug reporting, test execution, and QA documentation.

## Testing Scope
- Adding and deleting tasks
- Marking tasks as completed
- Filtering tasks
- Input validation
- Boundary value testing
- Exploratory testing

## Tools
- Jira — bug tracking and workflow practice
- Google Sheets and Microsoft Excel — test documentation
- GitHub — portfolio and version control

## QA Documentation
This repository will include:
- Test cases
- Test checklists
- Bug report examples
- Test execution reports
- Retesting examples

## Project Status
In progress — learning and portfolio development.

**Note:** Some test results and bug reports are training simulations. They are clearly identified and should not be interpreted as confirmed defects found during real application testing.
